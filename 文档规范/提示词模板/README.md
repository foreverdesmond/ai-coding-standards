## 使用方法

每次派发使用：

```text
00-公共基座
  + 一个按需角色模板
  + 该角色所需基线
  + Context L2（仅触发时）
  + 当前动态数据
```

尖括号字段必须替换。模板不能直接空白派发，也不能替代执行者自主探索。

## 动态数据最低要求

- 仓库和工作区；
- 来源与目标分支；
- TaskType、任务分支、worktree、BaseSHA、HeadSHA、ReviewedCommitRange、ReviewedCommitSet 和 MergeTarget；
- 不可歧义基线或候选目标；
- 上游文档及版本；
- 上下文包路径与状态（适用时）；
- 当前任务、风险和权限；
- 测试、Findings 或 NotRun；
- 期望的结构化输出。
